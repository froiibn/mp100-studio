# MP-100 리메이크 v1

2009년 MP-100의 로컬 MP3 플레이어를 다시 구현했습니다. Swing 화면에 원본 GIF 버튼을 사용하고, MP3 재생에는 JavaFX Media를 사용합니다.

## 실행

JDK 21 이상과 Maven 3.9가 필요합니다. `remake-v1` 폴더에서 실행합니다. 처음 실행할 때 Maven이 라이브러리를 내려받습니다.

```powershell
mvn javafx:run
```

창에서 MP3를 추가한 뒤 목록의 행을 선택하고 재생 버튼을 누릅니다. 중복 추가를 지원하며, 현재 재생 중인 행을 삭제하면 재생도 정지합니다. 곡이 끝나면 다음 재생 입력을 기다립니다. 목록은 앱을 사용하는 동안 메모리에 유지됩니다.

## 테스트

```powershell
mvn test
```

가짜 재생 엔진으로 정지 후 재재생, 곡 전환, 중복 행 삭제, 재생 종료와 실패, 취소 뒤 늦게 도착한 이벤트를 검증합니다. 이 테스트는 화면이나 오디오 장치 없이 실행됩니다.
